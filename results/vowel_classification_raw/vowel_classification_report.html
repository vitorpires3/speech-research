Warnings and interpretation cautions

  • Bandwidth handling: B1 -> B1_Hz using exp(B1); B2 -> B2_Hz using exp(B2); B3 -> B3_Hz using exp(B3)
  • LDA shrinkage__ALL_SAFE_NUMERIC, fold 1: Skipping features without any observed values: ['chunk_offset' 'chunk_part']. At least one non-missing value is needed for imputation with strategy='median'.
  • Logistic regression__ALL_SAFE_NUMERIC, fold 1: Skipping features without any observed values: ['chunk_offset' 'chunk_part']. At least one non-missing value is needed for imputation with strategy='median'.
  • Random forest__ALL_SAFE_NUMERIC, fold 1: Skipping features without any observed values: ['chunk_offset' 'chunk_part']. At least one non-missing value is needed for imputation with strategy='median'.
  • One CSV row is treated as one vowel token, consistent with the new-fave point output used here.
  • Balanced accuracy and macro-F1 are more informative than ordinary accuracy because /u/ is rarer.
  • The test sets were never oversampled or undersampled.
  • The current study uses raw features. A Lobanov comparison can later use the exact same speaker folds.
  • Model comparison is exploratory; hyperparameters were fixed rather than tuned on the outer test folds.
