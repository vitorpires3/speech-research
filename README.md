# Pesquisa de análise da fala

## Objetivo

Analisar características acústicas da fala em diferentes variedades do espanhol.

## Ferramentas

- Praat
- Python
- R
- VSCodium
- Git/GitLab

## Estrutura

- `dados/brutos`: dados originais
- `dados/processados`: tabelas tratadas
- `scripts/praat`: scripts de extração acústica
- `scripts/python`: limpeza e processamento
- `scripts/r`: análise estatística
- `resultados`: tabelas e gráficos

## Fluxo inicial

1. Selecionar uma pequena amostra.
2. Extrair medidas acústicas no Praat.
3. Exportar para CSV.
4. Limpar os dados em Python.
5. Analisar e visualizar em R ou Python.
